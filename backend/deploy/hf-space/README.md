# Corpus Vivo — API de desarrollo

Servicio de aplicación de **Corpus Vivo** (Universidad Peruana Unión, Filial Juliaca): una
plataforma para escuchar, explorar, jugar y enriquecer colaborativamente un corpus de quechua.

- Documentación interactiva: `/docs` · Contrato OpenAPI: `/openapi.json`
- Entorno de **desarrollo**: los datos pueden reiniciarse; las grabaciones subidas se pierden
  al reiniciar el Space.

Corpus provisional: AmericasNLP 2021 (quechua–español), audio sintético MMS-TTS, imágenes de
Wikimedia Commons con licencias libres (autor y licencia en cada respuesta de la API).
